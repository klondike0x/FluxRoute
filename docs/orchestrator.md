# Оркестратор

Оркестратор — это интеллектуальная система автоматического подбора стратегий обхода DPI.

## Режимы работы

### Ручной режим
Вы самостоятельно выбираете стратегию из выпадающего списка. Подходит, когда вы точно знаете, какая стратегия работает.

### Автоматический режим (Автовыбор)
Оркестратор сам:
1. Тестирует доступные стратегии.
2. Оценивает их эффективность (скорость, стабильность).
3. Выбирает лучшую стратегию.
4. Автоматически переключается при ухудшении качества.

## Как работает авто-подбор

1. **Тестирование** — оркестратор по очереди проверяет каждую стратегию на доступность целевых сайтов.
2. **Оценка** — каждой стратегии присваивается рейтинг на основе:
   - Доступности сайтов (YouTube, Discord, TikTok и др.)
   - Скорости загрузки
   - Стабильности соединения
3. **Выбор** — применяется стратегия с наивысшим рейтингом.
4. **Мониторинг** — оркестратор постоянно следит за качеством соединения.
5. **Fallback** — если текущая стратегия перестала работать, автоматически выбирается следующая.

## Компоненты оркестратора (v1.7.0)

Начиная с версии 1.7.0, оркестратор управляет компонентами независимо:

| Компонент | Описание | Статус |
|---|---|---|
| **Zapret** | Основной движок обхода DPI | Активен |
| **Zapret2** | Новый движок (альтернативный) | По выбору |
| **DNS** | Настройки DNS-серверов | Настраивается |
| **TG Proxy** | MTProto-прокси для Telegram | Активен |
| **DoH** | DNS-over-HTTPS шифрование | По выбору |

Каждый компонент можно включить/выключить независимо.

## Быстрое переключение движков

В панели оркестратора доступна кнопка быстрого переключения между Zapret и Zapret2:
- Одно нажатие — смена движка.
- Автоматическая проверка работоспособности перед переключением.

## ИИ-оркестратор

Расширенный режим с применением алгоритмов машинного обучения:
- **Thompson Sampling** — вероятностный выбор стратегий.
- **Генетический алгоритм** — эволюция параметров стратегий.
- **Анализ сетевых отпечатков** — адаптация под конкретного провайдера.
