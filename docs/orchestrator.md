# Оркестратор

Оркестратор автоматически проверяет профили FluxRoute и выбирает рабочую стратегию для выбранных целей.

## Первый запуск

Если рейтинг стратегий ещё не построен, первое включение оркестратора запускает первичную проверку всех доступных стратегий. Проверка выполняется для целей, выбранных в OnBoard: YouTube, Discord или YouTube + Discord.

После завершения рейтинги сохраняются. При следующих запусках оркестратор использует сохранённые результаты и не открывает первичное сканирование заново.

Если проверка была пропущена в OnBoard, это не отключает оркестратор: программа сама предложит выполнить её при первом запуске оркестратора.

## Режимы

### Ручной режим

Выберите компонент и профиль самостоятельно. Этот режим подходит для проверки конкретного BAT-профиля или фиксированной конфигурации.

### Автовыбор

Оркестратор:

1. запускает доступные профили;
2. проверяет выбранные сайты;
3. рассчитывает оценку от 0 до 100%;
4. применяет лучший профиль;
5. может повторить выбор при ухудшении качества.

## Цели и домены

На вкладке **Оркестратор** можно выбрать встроенные цели и добавить пользовательские домены. Список целей используется при проверке стратегий и в мониторинге.

## Обычный и ИИ-оркестратор

Обычный оркестратор строит рейтинг существующих профилей. ИИ-оркестратор дополнительно использует Thompson Sampling, историю проб, сетевой отпечаток и генетическую эволюцию для создания новых вариантов в `engine/ai-evolved/`.

## Компонент

Оркестратор работает с выбранным компонентом. Классический Zapret использует BAT-профили Flowseal; Zapret2 имеет отдельные проверки состояния и профили. Переключение компонента выполняется на главном экране.
