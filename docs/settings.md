# Настройки

Откройте боковую панель → **Настройки**.

## Приложение

Здесь находятся параметры:

- запускать FluxRoute в трее;
- использовать планировщик для автозапуска;
- задавать задержку автозапуска;
- автоматически запускать последний профиль;
- показывать предупреждение при смене стратегии;
- выбрать размер окна при запуске;
- добавить папку FluxRoute в исключения антивируса.

## Обновления

На вкладке **Обновления** доступны отдельные проверки для:

- движка Flowseal и папки `engine/`;
- самого приложения FluxRoute.

Тип пакета приложения выбирается автоматически: installer-установка получает installer, Portable — portable ZIP. Подробнее: [Обновления](updates.md).

## О программе

Содержит текущую версию, ссылки на репозиторий и сведения о лицензии.

## Где хранятся данные

FluxRoute сейчас использует portable-first хранение настроек: `fluxroute-settings.json`, резервная копия и файлы реестра ИИ находятся рядом с `FluxRoute.exe`. Для установленной версии обычно требуется запуск с правами администратора, чтобы приложение могло записывать данные в папку установки.
