# Безопасность

## Права администратора

FluxRoute требует права администратора для:

- работы с WinDivert и сетевым драйвером;
- запуска `winws.exe` и `winws2`;
- изменения DNS-настроек DoH;
- обновления файлов установленной версии в `Program Files`.

Без прав администратора часть функций будет недоступна.

## Исключения антивируса

Низкоуровневые сетевые компоненты WinDivert и `winws.exe` могут вызывать ложные срабатывания. Используйте кнопку **Настройки → Приложение → Добавить в исключения антивируса** или добавьте папку FluxRoute вручную в исключения Защитника Windows.

## Данные пользователя

FluxRoute не собирает телеметрию и не отправляет данные третьим лицам.

- Настройки и связанные файлы: рядом с `FluxRoute.exe`.
- Логи Serilog: `%LOCALAPPDATA%\FluxRoute\logs\`.
- Движок и моды: подпапки `engine/` и `mods/` рядом с приложением.

Не отправляйте диагностический пакет публично, если он содержит пользовательские домены или другую чувствительную информацию.

## Сетевые запросы

Приложение обращается к GitHub для проверки релизов и загрузки обновлений, к источнику Flowseal для движка, к выбранным DNS-провайдерам при включённом DoH и к целевым сайтам во время диагностики и проверки стратегий.
