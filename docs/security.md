# Безопасность

## Права администратора

FluxRoute требует права администратора для:
- Установки сетевых драйверов (WinDivert)
- Изменения DNS-настроек (DoH)
- Перехвата и модификации сетевых пакетов (DPI-обход)

Без прав администратора программа запустится в режиме ограниченной функциональности.

## Исключения антивируса

FluxRoute использует низкоуровневые сетевые компоненты, которые могут определяться антивирусом как подозрительное ПО. Это **ложное срабатывание**.

### Автоматическое добавление (рекомендуется)
1. Откройте **Настройки → Приложение**.
2. Нажмите **«Добавить в исключения антивируса»**.
3. Подтвердите действие (требуются права администратора).

### Ручное добавление в Защитник Windows
1. Откройте **Параметры Windows → Безопасность Windows → Защита от вирусов и угроз**.
2. Нажмите **Управление настройками** в разделе «Параметры защиты от вирусов».
3. Прокрутите до **Исключения → Добавить или удалить исключения**.
4. Нажмите **Добавить исключение → Папка**.
5. Выберите папку с FluxRoute (обычно `C:\FluxRoute`).

## Данные пользователя

FluxRoute **не собирает** телеметрию и **не отправляет** данные третьим лицам. Вся информация хранится локально:
- Настройки: `%APPDATA%\FluxRoute\fluxroute-settings.json`
- Логи: `%APPDATA%\FluxRoute\logs\`
- Движок: локальная папка установки

## Сетевые запросы

FluxRoute выполняет следующие сетевые запросы:
- **GitHub API** — проверка обновлений движка и приложения.
- **SourceForge** — загрузка движка (зеркало).
- **DNS-серверы** — при включённом DoH (Cloudflare, Google, Quad9).
- **Целевые сайты** — проверка доступности в диагностике.

Все HTTP-запросы выполняются через `IHttpClientFactory` с Polly retry.
