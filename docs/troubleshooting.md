# Решение проблем

## Частые вопросы

### «Не удалось запустить движок»
1. Убедитесь, что у вас есть права администратора.
2. Проверьте, не блокирует ли антивирус файлы движка.
3. Откройте **Настройки → Приложение → Добавить в исключения антивируса**.
4. Попробуйте переустановить движок: **Настройки → Обновления → Переустановить**.

### «Стратегия не работает»
1. Проверьте диагностику: вкладка **Диагностика → Проверить сайты**.
2. Если все сайты недоступны — проблема с движком или правами.
3. Если часть сайтов доступна — попробуйте другую стратегию.
4. Включите **Автовыбор** — оркестратор сам подберёт работающую стратегию.

### «Программа не запускается»
1. Установите [.NET 10 Runtime](https://dotnet.microsoft.com/download/dotnet/10.0).
2. Проверьте, что распакованы ВСЕ файлы из архива.
3. Запустите от имени администратора.
4. Проверьте журнал: `%APPDATA%\FluxRoute\logs\`.

### «Высокая нагрузка на CPU»
1. Проверьте, не запущено ли несколько копий FluxRoute.
2. Отключите автовыбор (переключите в режим «Вручную»).
3. Уменьшите количество проверяемых сайтов в диагностике.

### «Антивирус удаляет файлы»
FluxRoute использует низкоуровневые сетевые драйверы (WinDivert), которые могут определяться антивирусом как подозрительные. Это ложное срабатывание.

1. Откройте **Настройки → Приложение → Добавить в исключения антивируса**.
2. Или вручную:
   - Защитник Windows: Параметры → Безопасность Windows → Защита от вирусов → Управление настройками → Исключения → Добавить папку `C:\FluxRoute`
   - Другие антивирусы: добавьте папку программы в исключения.

### «YouTube грузится медленно»
1. Попробуйте стратегию **YouTube (оптимизированная)**.
2. Включите **Game Filter** в настройках службы.
3. Убедитесь, что выбрана правильная страна/регион в настройках.

### «Discord не подключается к голосовым каналам»
1. Используйте стратегию **Discord**.
2. Включите **Обход блокировок Discord** в настройках диагностики.
3. Проверьте, что порты Discord не блокируются брандмауэром.

### «Telegram не работает»
1. Проверьте статус TG Proxy на главном экране.
2. В настройках Telegram: Настройки → Продвинутые → Тип подключения → Использовать прокси → SOCKS5 → `127.0.0.1:1080`.

## Логи и диагностика

Логи приложения находятся в папке:
```
%APPDATA%\FluxRoute\logs\
```

При обращении в поддержку приложите файл `fluxroute-*.log` — это ускорит решение проблемы.

## Сброс настроек

Если программа работает некорректно:
1. Закройте FluxRoute.
2. Удалите файл `%APPDATA%\FluxRoute\fluxroute-settings.json`.
3. Запустите программу заново — настройки сбросятся к значениям по умолчанию.
