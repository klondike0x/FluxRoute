# Быстрый старт

## Установка

1. Скачайте последнюю версию из [раздела релизов](https://github.com/klondike0x/FluxRoute/releases).
2. Распакуйте архив в любую папку (рекомендуется `C:\FluxRoute`).
3. Запустите `FluxRoute.exe` от имени администратора.

## Первый запуск

При первом запуске FluxRoute:

1. **Проверка прав администратора** — программа запросит права администратора (необходимы для работы DPI-обхода).
2. **Автоматическая загрузка движка** — FluxRoute автоматически скачает последнюю версию Flowseal (движка zapret).
3. **Выбор стратегии** — выберите стратегию из списка. Для начала рекомендуется «Универсальная» или «YouTube + Discord».
4. **Запуск защиты** — нажмите большую кнопку на главном экране.

## Требования

- Windows 10/11 (x64)
- .NET 10 Runtime (устанавливается автоматически)
- Права администратора
- Подключение к интернету для загрузки движка

## Что делать, если...

### ...сайты не открываются?
1. Проверьте, что защита запущена (зелёный индикатор).
2. Попробуйте другую стратегию в выпадающем списке.
3. Откройте вкладку **Диагностика** и запустите проверку.

### ...антивирус блокирует программу?
1. Откройте **Настройки → Приложение**.
2. Нажмите **«Добавить в исключения антивируса»**.
3. Или вручную добавьте папку `C:\FluxRoute` в исключения Защитника Windows.

### ...нужно обновить движок?
1. Откройте **Настройки → Обновления**.
2. Нажмите **«Проверить обновления»**.
3. Если доступна новая версия — нажмите «Установить».
