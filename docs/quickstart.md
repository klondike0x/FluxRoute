# Быстрый старт

## Установка

1. Скачайте последний релиз из [раздела Releases](https://github.com/klondike0x/FluxRoute/releases).
2. Выберите вариант:
   - **Installer** — установите FluxRoute в папку по умолчанию.
   - **Portable** — распакуйте ZIP в любую папку, например `C:\FluxRoute`.
3. Запустите `FluxRoute.exe` от имени администратора.

Релизы Windows собираются self-contained, поэтому отдельная установка .NET Runtime не требуется.

## Первый запуск

OnBoard последовательно предложит:

1. Выбрать компонент — классический **Zapret**, **Zapret2** или вариант без основного компонента.
2. Выбрать, что проверять — **YouTube**, **Discord** или **YouTube + Discord**.
3. Запустить настройку и первичную проверку стратегий.

Кнопка **«Настроить и продолжить»** запускает проверку выбранных целей. Кнопка **«Продолжить без проверки»** открывает программу без первичного сканирования.

Если проверка была пропущена, она автоматически запустится при первом включении оркестратора. После успешного сканирования повторная проверка при каждом запуске оркестратора не требуется.

## Основные шаги после запуска

1. При необходимости обновите `engine/` на вкладке **Настройки → Обновления**.
2. Проверьте компоненты на вкладке **Диагностика**.
3. Запустите защиту на главном экране.
4. Для автоматического выбора профиля включите оркестратор.

## Требования

- Windows 10/11 x64
- Права администратора для WinDivert, движка и изменения DNS
- Подключение к интернету для загрузки движка и проверки сайтов

## Обновление

- Установленная через installer версия получает новый installer прямо из встроенного обновления.
- Portable-версия обновляется через portable ZIP.
- Пользовательские настройки не удаляются при обновлении.
