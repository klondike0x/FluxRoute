# Обновления

Откройте боковую панель → **Настройки → Обновления**.

## Обновление движка

Блок **Flowseal Zapret** проверяет и обновляет содержимое `engine/`. Во время установки `winws.exe` останавливается. После обновления запустите защиту или профиль заново.

## Обновление FluxRoute

Блок **FluxRoute (приложение)** проверяет официальный репозиторий `klondike0x/FluxRoute`.

- Если FluxRoute установлен через installer, скачивается новый `FluxRoute-vX.Y.Z-installer.exe`, он запускается с UAC и обновляет текущую установку поверх старой.
- Если FluxRoute запущен как Portable, скачивается `FluxRoute-vX.Y.Z-portable.zip`, после чего файлы заменяются в текущей папке.
- После обновления приложение перезапускается.
- Настройки и пользовательские файлы, не входящие в пакет релиза, не удаляются.

Если обновление из интерфейса не удалось, скачайте нужный installer или ZIP вручную со страницы [Releases](https://github.com/klondike0x/FluxRoute/releases).
## Безопасность релизов

Официальные релизы публикуются один раз как immutable releases. Их Git-тег и файлы нельзя изменить после публикации.

В каждом релизе доступны:

- SHA256SUMS.txt — хеши Installer и Portable;
- SHA256SUMS.txt.asc — GPG-подпись манифеста;
- GPG-by-klondike0x.asc — публичный ключ релизов.

Проверяйте подпись и хеши перед запуском файлов. Дополнительно GitHub публикует provenance attestation для артефактов сборки.
## Публикация нового релиза

Релизный тег должен быть подписан тем же GPG-ключом:

    git tag -s vX.Y.Z -m "FluxRoute vX.Y.Z"
    git push origin vX.Y.Z

После публикации immutable-релиза workflow не перезаписывает его и не использует --clobber.
