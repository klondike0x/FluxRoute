# Диагностика

Откройте боковую панель → **Диагностика**.

## Быстрое состояние

Страница показывает:

- наличие прав администратора;
- состояние папки `engine/`;
- наличие `winws.exe`;
- наличие `WinDivert.dll`;
- наличие драйвера `WinDivert.sys`;
- версию приложения.

## Действия

- **Запустить диагностику** — выполнить расширенную проверку компонентов и соединения.
- **Обновить** — перечитать состояние профилей и движка.
- **Скопировать** — скопировать краткую диагностику.
- **Экспорт логов** — сохранить доступные логи.
- **Диагностический пакет** — собрать ZIP с логами, диагностикой и настройками для отправки в Issue.

Перед обращением за помощью запустите диагностику, воспроизведите проблему и приложите результат вместе с версией FluxRoute.
