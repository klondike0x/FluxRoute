# Главный экран

Главный экран FluxRoute — это центр управления защитой. Здесь вы можете запустить/остановить обход блокировок и видеть текущий статус.

## Элементы главного экрана

### Кнопка защиты (центр экрана)
- **Запустить** — нажимайте, когда защита выключена (красный индикатор).
- **Остановить** — нажимайте, когда защита включена (зелёный индикатор).
- Во время работы отображается скорость трафика (↓ входящий, ↑ исходящий).

### Статус защиты
- **Активна** — зелёный индикатор, защита работает, трафик проходит через zapret.
- **Не активна** — красный индикатор, защита выключена.
- **Запуск...** — жёлтый индикатор, идёт инициализация движка.

### Переключатель режимов (над кнопкой)
- **Вручную** — вы сами выбираете стратегию из списка.
- **Автовыбор** — ИИ-оркестратор автоматически подбирает лучшую стратегию.

### Выбор стратегии (под кнопкой)
Выпадающий список доступных профилей (стратегий):
- **Универсальная** — общая стратегия для большинства сайтов.
- **YouTube** — оптимизирована для YouTube.
- **Discord** — оптимизирована для Discord.
- И другие...

### Карточки состояния (правая панель)
- **Zapret** — статус движка обхода.
- **TG Proxy** — статус встроенного MTProto-прокси.
- **DoH** — статус DNS-over-HTTPS.
- **Оркестратор** — статус ИИ-подбора стратегий.

## Горячие клавиши
- **Ctrl+Q** — запустить/остановить защиту.
- **Из трея** — правый клик по иконке в трее для быстрого управления.
